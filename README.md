# Smart-Egg-Incubator
-------
This project documents the final implementation and validation of a Smart Egg Incubator based on 
an ESP32 running FreeRTOS. The prototype performs local temperature and humidity monitoring, 
relay-based actuator control, automatic egg turning, local OLED status display, audible safety 
alarms, incubation-day tracking, and remote monitoring/manual control through the Blynk IoT 
platform.
